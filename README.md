# Dead by Daylight 资料站

《黎明杀机》（Dead by Daylight）中文资料站，纯静态页面：没有构建步骤，没有依赖，
直接用浏览器打开 `index.html` 就能看，也可以整目录丢给任意静态服务器 / GitHub Pages。

## 页面

| 文件 | 内容 |
| --- | --- |
| `index.html` | 首页（导航与概览） |
| `killers.html` | 杀手 |
| `survivors.html` | 逃生者 |
| `perks.html` | 技能 |
| `maps.html` | 地图 |

## 目录

- `css/` `js/` `images/` —— 样式、脚本、图标与图片素材
- `道具与祭品图标清单.md` / `.json` —— 道具与祭品图标对照表
- `学习笔记-从一个真实项目学做网站.md` —— 建站过程记录
- `部署说明.md`、`宝塔部署步骤.txt` —— 部署文档
- `打包报告-重命名清单.txt` —— 图片重命名与打包记录

## 说明

- 仓库只收录源文件。`dist/`（压缩后的发布副本）和 `*.zip` 打包产物属于构建结果，未纳入版本控制。
- 纯静态站点，`git clone` 后直接部署即可，无需安装任何环境。
