宝塔面板部署步骤（www.pcqweb.com 复用已有站点）
================================================

背景：www.pcqweb.com 已经是宝塔里一个带 SSL 证书的站点（证书剩余约 89 天）。
我们不新建站点（同域名新建会撞车、还会丢掉现成证书），而是直接替换它的网站文件。

产物：D:\DBD-website\DBD-website-dist.zip   （372 个文件，27.85 MB）


【第 0 步】先确认域名解析（1 分钟）
----------------------------------
在你自己电脑上打开 PowerShell 执行：

    Resolve-DnsName www.pcqweb.com | Select-Object Name, IPAddress

看 IPAddress 是不是 43.167.10.134。

  - 是      -> 继续第 1 步
  - 不是    -> 去域名服务商控制台，把 www 的 A 记录改成 43.167.10.134，等 5-10 分钟生效
  - 查不到  -> 同上，说明解析还没配

同时去腾讯云控制台 -> 轻量应用服务器 -> 防火墙，确认放行了 80 和 443 端口。


【第 1 步】备份旧文件（重要，别跳过）
----------------------------------
1. 宝塔左侧菜单 -> 网站
2. 在站点列表里找到 www.pcqweb.com，点它那一行的「根目录」，会跳到文件管理器
   记下这个路径，通常是 /www/wwwroot/www.pcqweb.com

3. 在文件管理器里新建一个备份目录：
   点上方「新建」-> 目录 -> 名字填：backup_20250613（用当天日期）

4. 回到根目录，全选文件（Ctrl+A），点「剪切」
   ！注意：默认可能不显示隐藏文件。点右上角「显示隐藏文件」，
     确认连 .user.ini、.htaccess 这类点开头的文件也一起选中了

5. 进入 backup_20250613 目录，点「粘贴」
   -> 此时根目录应该空了（只剩 backup_20250613 这个目录）

回滚方法：万一新站有问题，把 backup_20250613 里的文件剪回上一层即可。


【第 2 步】上传并解压
----------------------------------
1. 回到网站根目录（/www/wwwroot/www.pcqweb.com）
2. 点上方「上传」，选择 DBD-website-dist.zip
   27.85 MB，浏览器上传一般十几秒到一分钟

   如果上传失败或太慢，改用 FTP：宝塔左侧「文件」页面顶部有 FTP 信息，
   用 FileZilla 连上去传。

3. 上传完，在文件列表里右键点 DBD-website-dist.zip -> 「解压」
4. 解压完把 zip 本身删掉（右键 -> 删除），别留在网站目录里


【第 3 步】检查解压结果（最常见的翻车点）
----------------------------------
解压后根目录必须是这个样子：

    /www/wwwroot/www.pcqweb.com/
        index.html          <- 必须在最外层
        survivors.html
        killers.html
        perks.html
        maps.html
        css/
        js/
        images/
        backup_20250613/    <- 备份，暂时留着
        DBD-website-dist.zip <- 记得删掉

如果变成这样（多套了一层 dist），首页会打不开：

    /www/wwwroot/www.pcqweb.com/dist/index.html   <- 错的

修法：进入 dist 目录，Ctrl+A 全选，剪切，回到上一层粘贴，再把空的 dist 删掉。


【第 4 步】验证
----------------------------------
浏览器打开：

    http://www.pcqweb.com          应显示「黎明杀机资料库」首页
    https://www.pcqweb.com         也应正常（复用原证书）

然后点进「地图大全」页，看那 55 张地图图能不能显示。
这一页是唯一可能出问题的地方，因为那批图是 WebP 格式（源文件名却是 .png，
打包时已修正为 .webp）。

  能显示   -> 全部搞定，完成
  不显示   -> 服务器的 MIME 缺 image/webp，按下面处理


【第 4 步的补救】地图图不显示时
----------------------------------
宝塔用的是 nginx。先查它认不认识 webp：

    宝塔左侧「终端」，或 SSH 连上去执行：
    grep webp /etc/nginx/mime.types

  - 有输出 -> 不是 MIME 问题，回来找我
  - 无输出 -> 编辑 /etc/nginx/mime.types，在文件里其他 image/* 行旁边加一行：

        image/webp  webp;

    然后在宝塔「软件商店」-> Nginx -> 点「重载配置」
    （或在终端执行 nginx -t && nginx -s reload）


【第 5 步】稳定后再清理
----------------------------------
确认网站正常跑几天后，可以删掉 backup_20250613 目录释放空间。
不急，留着也不影响访问。


================================================
备忘
================================================
- dist/ 里的 preview.mjs 和 .htaccess 是给本地预览和 Apache 用的，
  在宝塔（nginx）下不起作用，留着无害，也可以删。
- 该站是纯静态站，没有数据库、没有后端进程，宝塔里不用配「项目部署」，
  也不用装 PHP/Java/Node 任何运行时。
- 更新网站时，只需重新上传新的 index.html / css / js / images 覆盖即可。
